# Log File Analyzer 📄

A Python-based Log File Analyzer that reads a log file and analyzes different types of system messages.

## Features

- Reads log files
- Counts INFO messages
- Counts SUCCESS messages
- Counts WARNING messages
- Counts ERROR messages
- Displays total log entries
- Creates a sample log file

## Technologies Used

- Python
- File Handling
- Strings
- Loops
- Conditional Statements

## How to Run

python log_file_analyzer.py

## Concepts Used

- File handling
- Reading files
- String processing
- Loops
- Conditional statements
- Data analysis

## Purpose

This project demonstrates practical file handling and
basic log analysis using Python.
